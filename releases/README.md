# Brauzio — تثبيت النسخة الجاهزة

## تثبيت إضافة Chrome

1. نزّل ملف ZIP الجاهز من Artifact الخاص بـ **Brauzio CI** في GitHub Actions.
2. فك ضغط الملف.
3. افتح `chrome://extensions/` في Chrome.
4. فعّل **وضع المطور**.
5. اضغط **تحميل إضافة غير مضغوطة**.
6. اختر المجلد الذي فككت ضغطه.

## الاتصال بـ Brauzio Cloud

Brauzio لا يحتاج إلى Native Server محلي ولا إلى المنفذ `12306` ولا إلى Node.js لدى المستخدم النهائي.

من نافذة الإضافة:

1. أدخل رابط Brauzio Cloud المنشور على Cloudflare.
2. استخدم معرف الجهاز ورمز الاقتران الخاصين بك.
3. اضغط اتصال.
4. بعد ظهور الحالة **متصل**، استخدم رابط MCP المعروض في إعداد ChatGPT Custom MCP.

## استكشاف الأخطاء

- إذا لم تُحمّل الإضافة، تأكد من اختيار مجلد الإضافة المفكوك نفسه وليس المجلد الأب.
- إذا لم يتصل Brauzio Cloud، تحقق من رابط Worker ومن رمز الاقتران.
- إذا انقطع الاتصال، جرّب **إعادة الاتصال** من نافذة Brauzio.
- راجع `docs/TROUBLESHOOTING.md` للتشخيص التفصيلي.

## تنبيه أمني

Brauzio يمتلك صلاحيات متقدمة للتحكم في المتصفح. استخدم فقط خادم Cloudflare الذي تملكه ولا تشارك رموز الاقتران أو مفاتيح الوصول.
